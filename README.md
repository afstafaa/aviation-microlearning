# Aviation Microlearning

An illustrated browser-based FAA microlearning prototype.

## Paths

- `index.html`: library home page
- `part91/subpart-a/`: Subpart A, General
- `part91/subpart-b/`: Subpart B, VFR and IFR

## Publish

GitHub Pages → Deploy from a branch → `main` → `/(root)`.

Designed to work at `https://USERNAME.github.io/aviation-microlearning/` with relative URLs.

Educational prototypes only; aircraft illustrations and scenarios are not flight instructions or regulatory authority.
